# BrowseBlock SRS

> [!TIP]
> 📑 [Click here to view the Full Literature Review (`review.pdf`)](./review.pdf)

Welcome to the repository for the BrowseBlock - Software Requirements Specification(SRS), written in LaTeX. This project serves as a centralized, version-controlled source for the document, allowing for clean formatting and easy updates.

## 🚀 How to Build

To compile the PDF from the LaTeX source code, you will need a LaTeX distribution installed on your system, such as TeX Live, MiKTeX, or MacTeX.

Clone the repository:

```bash
git clone https://github.com/deon-george/BrowseBlock_SRS.git
cd BrowseBlock_SRS
```

Compile the document:

You can compile the `.tex` file using `pdflatex`:

```bash
pdflatex review.tex
```

This will generate a `review.pdf` file in the same directory.

Alternatively, you can use online editors like Overleaf by simply uploading the `.tex` file.

## 📁 Repository Structure

- `review.tex`: The main LaTeX source file containing the literature review content and formatting.
- `review.pdf`: The compiled, ready-to-view PDF version of the literature review.
- `.gitignore`: Git configuration to ignore temporary LaTeX build artifacts.
- `README.md`: This file, providing an overview of the repository.
